# ZipDock — архиватор и делитель файлов для iOS

Нативное iOS-приложение (SwiftUI). Работает локально, без API и без VPS.

**Функции:**
- создание ZIP из файла или папки (Deflate);
- распаковка ZIP;
- деление произвольного большого файла на части 20/50/100/200 МиБ;
- обратная побайтовая сборка `.part001`, `.part002` и т.д.;
- отправка готовых частей через системное меню Share;
- результаты в «Файлы» → «На iPhone» → ZipDock → «Результаты».

## Сборка IPA на GitHub без Mac

1. Создай **пустой публичный или приватный GitHub-репозиторий**.
2. Загрузи **всё содержимое** этого архива в корень репозитория, включая скрытую папку `.github/workflows`.
3. Открой вкладку **Actions** → **Build unsigned iOS IPA** → **Run workflow** (либо дождись запуска после загрузки в ветку `main`).
4. Открой успешный запуск → **Artifacts** → `ZipDock-iOS-IPA`.
5. GitHub выдаст ZIP с `ZipDock-unsigned.ipa`. Распакуй его в «Файлах» и импортируй IPA в LiveContainer.

> Это **неподписанный IPA** для LiveContainer. Обычная установка на домашний экран без подписи не заработает. Совместимость со всеми конфигурациями LiveContainer не гарантируется.

## Как отправить большой TikTok IPA

1. Открой ZipDock → **Разделить** → **50 МБ**.
2. Выбери `.ipa` в приложении «Файлы».
3. После завершения будут файлы `TikTok.ipa.part001` и т.д.
4. Прикрепи каждую часть в чат по отдельности; не переименовывай.
5. Для восстановления выбери все части в режиме **Собрать**.

ZIP и деление — разные операции. Деление не уменьшает суммарный размер, зато каждая часть меньше лимита загрузки.

## Технические детали

- iOS 17+, SwiftUI, ZIPFoundation через Swift Package Manager.
- Xcode-проект генерируется `xcodegen` в GitHub Actions.
- сборка выполняется на GitHub-hosted macOS runner.
- чтение и запись частей потоками по 1 МиБ, чтобы не держать весь IPA в памяти.
- байтовое объединение частей, а не «многотомный ZIP».

**Ограничения:** текущий интерфейс не выводит прогресс в процентах; повреждённые части не обнаруживаются по контрольной сумме; для надёжного экспорта целого набора частей сохраняй их из папки «Результаты» по отдельности. Успешная сборка в GitHub Actions и запуск на устройстве ещё не проверены здесь.
